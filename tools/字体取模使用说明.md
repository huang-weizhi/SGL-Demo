# 字体取模使用说明（ASCII 点阵字体）

本文说明怎么把新的 ASCII 字号加进 `Inf_lcd_font.h`，以及取模软件该怎么设置。
配套校验脚本：`app/tools/font_preview.py`（把点阵打印成字符画，肉眼确认字形）。

---

## 0. 一句话结论（取模软件设置）

用 **PCtoLCD2002**，设置为：

| 项目 | 选择 |
|---|---|
| 点阵格式 | **阴码** |
| 取模方式 | **逐行式** |
| 取模走向 | **逆向（低位在前）** |
| 输出格式 | **C51 格式**（十六进制） |
| 字宽 × 字高 | **宽 = 高 ÷ 2**（例：高 48 → 宽 24） |

生成的每个字符字节数必须等于 `ceil(宽/8) × 高`。

---

## 1. 本工程的字体格式（已用实际数据核对）

表文件：`app/project/interface/Inf_lcd_font.h`

| 表名 | 高 × 宽 | 字节/字符 | 95 字符占用 |
|---|---|---|---|
| `ascii_1206` | 12 × 6 | 12 | 1140 B |
| `ascii_1608` | 16 × 8 | 16 | 1520 B |
| `ascii_2412` | 24 × 12 | 48 | 4560 B |
| `ascii_3216` | 32 × 16 | 64 | 6080 B |
| `ascii_5628` | **56 × 28** | 224 | 21280 B |

> 最后一张由 PCtoLCD2002 直接导出（`const unsigned char ascii_5628[95][224]`），
> 声明形式是 `[字符数][每字符字节数]`，数据格式与上面四张完全一致
> （逐行式、低位在前、阴码）；`lcd_font_get()` 里对应 `case 56`，
> 宽度 28 = 56 / 2，符合"宽 = 高 / 2"规则。
> 注意：宽 28 不是 8 的倍数，每行占 4 个字节（32 位），多的 4 位是补齐位，
> `lcd_show_char()` 按宽度自动忽略，取模时不用手动处理。

四条硬规则（任何一条错都会花屏）：

1. **95 个字符，顺序固定**：`' '`(0x20) 到 `'~'`(0x7E)，下标 = 字符码 − 0x20。
   中间少一个字符，后面所有字符都会整体错位。
2. **数据走向 = 逐行式**：从上到下逐行，行内从左到右。
3. **位序 = 低位在前**：一个字节里 bit0 对应**最左边**那一列，1 = 亮点（阴码）。
4. **每行按整字节补齐**：字节数 = `ceil(宽/8) × 高`。
   例如 24 高 12 宽的 `ascii_2412` 每行 2 字节（16 位），高 4 位没用上，
   `lcd_show_char()` 会按宽度自动忽略这些补位。

代码侧对应关系：

- `Inf_lcd.c` 的 `lcd_font_get(size, ch, &width)`：按 `size` 选择表并给出宽度。
- `Inf_lcd.c` 的 `lcd_show_char()`：字节数 = `((sizex + 7) / 8) * size`，
  所以**表尺寸和 (宽, 高) 必须完全吻合**。
- `lcd_show_string()` / `lcd_show_int()` / `lcd_show_float()` 的字符步进是
  `size / 2`，所以**宽必须 = 高 / 2**，否则字会重叠或拉太开。

## 2. PCtoLCD2002 操作步骤

1. 打开 PCtoLCD2002，模式选 **字符模式**。
2. 点【选项】按钮，按第 0 节的表格设置四项；
   顺便把「每行显示数据」设为点阵 16 进制、一行 16 个，行前缀 `0x`、行后缀 `,`。
3. 用【字宽】【字高】设定尺寸（例：48 / 24）。
   宽度不是 8 的倍数没关系，软件会按整字节补齐（和现有表一致）。
4. 【字体】里选好字体与字符区间，生成 `' '`(0x20) ~ `'~'`(0x7E) 共 95 个字符。
5. 复制输出，粘贴到 `Inf_lcd_font.h` 末尾 `#endif` 之前。
6. **检查行尾反斜杠**（PCtoLCD2002 有个固定坑）：它给反斜杠字符生成的注释就是
   `//60 \` 这种形式，而 C 里**行尾反斜杠 = 续行符**，会把下一行整行吞进注释，
   于是花括号配对错乱，编译报错像这样：
   ```
   error: expected ';' at end of declaration
   error: extraneous closing brace ('}')
   ```
   解法：把那行注释末尾的反斜杠删掉（改成 `//60 backslash`），
   或者直接跑 `python font_preview.py`——它会自动扫出来并提示行号。

**选错设置的表现**（用 `font_preview.py` 可以快速反查）：

| 现象 | 说明 |
|---|---|
| 上下颠倒 / 错行 | 取模方式选错了（用了逐列式 / 列行式 / 行列式） |
| 左右镜像 | 取模走向选成了顺向（高位在前） |
| 只有零星几个点、大面积空白 | 用了阳码，或走向不对 |
| 字符横向错位、跨到下一个字 | 表尺寸与 (宽, 高) 不匹配 |
| 编译报 `expected ';' at end of declaration` | 注释里有行尾反斜杠（见第 6 步），`font_preview.py` 会自动检出 |
| 完全不显示、也不报错 | `lcd_font_get()` 里没有对应 `case`（字号没登记） |

小技巧：怀疑位序/方向选错时，用 `python font_preview.py 4824 A --msb`
按「高位在前」再渲染一次对比，哪个像字形哪个就是对的。

## 3. 添加一个新字号（以 48 高 24 宽为例）

### 步骤 1：粘贴点阵表到 `Inf_lcd_font.h`

放在文件末尾 `#endif` 之前，注意声明里的字节数要手改成实际值：

```c
/* 4824: 24x48 dot matrix (height 48, width 24), 144 bytes per char */
const unsigned char ascii_4824[][144] =
{
    { ... },/*" ",0*/
    { ... },/*"!",1*/
    /* ... 共 95 个字符 ... */
    { ... },/*"~",94*/
};
```

自检：`144 = ceil(24/8) × 48 = 3 × 48` ✔

### 步骤 2：在 `lcd_font_get()` 里加一个 case

文件：`app/project/interface/Inf_lcd.c`

```c
        case 32:
            *width = 16;
            return ascii_3216[ch];
        case 48:                        /* 新增 */
            *width = 24;
            return ascii_4824[ch];
        default:
            *width = 0;
            return 0;
```

### 步骤 3：调用时 `size` 传新字号

```c
lcd_show_string(20, 40, "TEMP", WHITE, 0x3186, 48, 0);
lcd_show_int(20, 110, this->actual_temp, 3, 1, WHITE, 0x3186, 48);
```

> 注意屏幕是 320×320：48 号字一个数字宽 24 px，一行最多放 13 个字符。

### Flash 占用估算（95 字符整表）

| 字号（高 × 宽） | 字节/字符 | 95 字符占用 |
|---|---|---|
| 40 × 20 | 120 | 11.1 KB |
| 48 × 24 | 144 | 13.4 KB |
| 64 × 32 | 256 | 23.8 KB |

当前固件 Flash 约 48.8 / 128 KB（余量约 79 KB），加一张 48 号表很宽裕；
若同时加多张，注意别超过 128 KB（大字体也可以只做数字，见第 5 节）。
RAM 不占——这些表是 `const`，只在 Flash 里。

## 5. 省 Flash：只做数字字体（可选）

大字号通常只用来显示数字，可以只取模 `0`~`9`、`-`、`.`、`:` 共 13 个字符：

- 48 号只做 13 个字符 = 13 × 144 = **1872 字节**（整表要 13.4 KB）

做法是把表换成这 13 个字符，再在 `lcd_font_get()` 里做一次下标映射
（注意：函数开头已经执行过 `ch = ch - ' '`，所以要 `ch + ' '` 还原字符码）：

```c
/* 只含 '0'~'9' '-' '.' ':' 的表，下标 0..12 */
static uint8_t ascii48_digit_index(uint8_t ch)
{
    if (ch >= '0' && ch <= '9') { return (uint8_t)(ch - '0'); }
    if (ch == '-') { return 10U; }
    if (ch == '.') { return 11U; }
    if (ch == ':') { return 12U; }
    return 0xFFU;                       /* 不在表里 */
}
```

```c
        case 48:
        {
            uint8_t idx = ascii48_digit_index((uint8_t)(ch + ' '));

            if (idx == 0xFFU)
            {
                *width = 0;                 /* 该字符没有点阵，跳过不显示 */
                return 0;
            }
            *width = 24;
            return ascii_4824_digit[idx];
        }
```

代价：这个字号只能显示表里有的字符，别的字符（字母、汉字）不显示。

## 6. 其他注意事项

1. **`size` 形参是 `uint8_t`**，字号最大 255；`lcd_show_char()` 里
   单个字符字节数用的是 `uint16_t`，所以字号别超过 255。
2. **透明模式很慢**：`lcd_show_char(..., mode = 1)` 是每个亮点单独
   `lcd_draw_point()`（每次都要重设窗口），大字号会明显拖慢刷新；
   能用 `mode = 0`（整字一次设窗口）就用 0，背景色传所处页面的底色即可：
   ```c
   lcd_show_int(20, 110, temp, 3, 1, WHITE, 0x3186, 48);   /* 末尾的 0x3186 是底色 */
   ```
3. **大字号没有抗锯齿**：字号越大，点阵字的锯齿越明显。要平滑效果得用
   TTF 渲染成灰度/抖动点阵（本工程目前不支持）。
4. **`lcd_show_int` 的 `len` 含负号**：48 号字 `len = 3` 表示最多 3 个字符位
   （负号占一位），一行宽度 = `len × 24`。
5. 若以后要支持「宽 ≠ 高/2」的字形，需要把 `lcd_show_string/int/float` 里
   写死的 `size / 2` 步进改成查表得到宽度，否则字会重叠。
